# Federation Boxing — Full Build 2.0

Полноценная тестовая сборка приложения Федерации бокса Иркутского округа.

## Что уже работает

- публичная страница Федерации
- вход по телефону с demo OTP
- автоматическое определение ролей
- кабинеты администратора, тренера, родителя и спортсмена
- залы, группы и код присоединения
- заявки родителей на ребёнка
- одобрение/отклонение тренером
- расписание, посещаемость, рейтинг и достижения
- групповые сообщения и уведомления
- CMS с версиями и публикацией
- аудит действий
- PostgreSQL + Docker + HTTPS через Caddy

## Обновление сервера

```bash
curl -fsSL https://raw.githubusercontent.com/Alex-138138/federation-boxing/main/deploy/update-full-build-2.sh -o /tmp/update-full-build-2.sh
bash /tmp/update-full-build-2.sh
```

Это всё ещё development/test build. Для production нужны реальный SMS-провайдер, VAPID push-ключи, финальные персональные данные/фото Федерации, резервное копирование и дополнительный security review.
